# 두 개의 자아 — 순수 HTML/JS 버전 (설치 없음)

Node.js, npm, 빌드 과정이 전혀 필요 없습니다. `index.html`을 그냥 더블클릭해서
브라우저로 열면 바로 동작합니다 (단, config.js에 Supabase 값을 넣은 뒤).

파일 구성:
- `index.html` — 페이지 구조
- `style.css` — 디자인
- `app.js` — 전체 로직 (설문 렌더링, 제출, 결과 계산, 차트, 실시간 구독)
- `config.js` — **여기에 본인 Supabase 값만 넣으면 끝**

## 1. Supabase 설정

React 버전과 동일합니다. Supabase 대시보드 → **SQL Editor**에서 아래 SQL 실행:

```sql
create table if not exists responses (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  job_level text not null check (job_level in ('사원/주임', '대리/과장', '차장 이상')),
  work_q1 int not null check (work_q1 between 1 and 5),
  work_q2 int not null check (work_q2 between 1 and 5),
  work_q3 int not null check (work_q3 between 1 and 5),
  work_q4 int not null check (work_q4 between 1 and 5),
  work_q5 int not null check (work_q5 between 1 and 5),
  mba_q1 int not null check (mba_q1 between 1 and 5),
  mba_q2 int not null check (mba_q2 between 1 and 5),
  mba_q3 int not null check (mba_q3 between 1 and 5),
  mba_q4 int not null check (mba_q4 between 1 and 5),
  mba_q5 int not null check (mba_q5 between 1 and 5)
);

alter table responses enable row level security;

create policy "Anyone can insert a response"
  on responses for insert
  to anon
  with check (true);

create policy "Anyone can read all responses"
  on responses for select
  to anon
  using (true);
```

그다음:
- **Database → Replication**에서 `responses` 테이블 Realtime **켜기**
- **Project Settings → API**에서 `Project URL`과 `anon public` 키 복사

## 2. config.js 채우기

`config.js` 파일을 텍스트 에디터(메모장, VS Code 등 아무거나)로 열어서:

```js
window.SUPABASE_URL = "https://abcdefgh.supabase.co";   // 본인 값으로 교체
window.SUPABASE_ANON_KEY = "본인의_긴_anon_키";           // 본인 값으로 교체
```

저장 후 닫기.

## 3. 로컬 확인

`index.html`을 더블클릭해서 브라우저로 열면 바로 동작합니다.
(만약 브라우저에서 파일을 직접 열었을 때 CORS 관련 오류가 뜨면, 아래처럼 간단한
로컬 서버로 열어보세요 — 터미널에서 이 폴더로 이동 후:

```bash
python3 -m http.server 8000
```
그리고 브라우저에서 `http://localhost:8000` 접속. Mac에는 Python이 기본 설치되어
있어서 별도 설치가 필요 없습니다.)

## 5. 배포 — 세 가지 방법 중 선택

### A. GitHub Pages (가장 추천 — 설치 아무것도 필요 없음)
1. github.com에서 방금 만든 저장소 페이지로 이동
2. **Settings → Pages** 클릭
3. "Build and deployment" → Source: **Deploy from a branch**
4. Branch: **main**, 폴더: **/ (root)** 선택 → **Save**
5. 1~2분 후 `https://본인아이디.github.io/저장소이름/` 형태의 URL 생성됨

### B. Netlify 드래그앤드롭 (GitHub도 필요 없음, 가장 빠름)
1. https://app.netlify.com 접속 (이메일로 가입)
2. 로그인 후 나오는 화면에 **폴더 전체를 그대로 드래그**해서 놓기
3. 몇 초 후 `https://아무이름.netlify.app` 형태의 URL 자동 생성

### C. Firebase Hosting (기존에 쓰시던 Firebase 계정 활용)
Node.js가 없어도 사이트 자체는 만들 수 있지만, Firebase에 "배포"하는 명령어
자체(`firebase deploy`)는 Firebase CLI가 필요하고, 이 CLI 설치에는 Node.js가
필요합니다. Node.js를 설치할 계획이 없다면 A 또는 B를 추천합니다. Node.js가
있다면:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # public directory 질문에는 "." (현재 폴더) 입력
firebase deploy --only hosting
```
